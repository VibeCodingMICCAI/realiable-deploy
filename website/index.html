What does this tool do?

Multi-structure knee MRI segmentation: the software takes a 3D MRI volume and produces a label map (and optional visuals / provenance). This page uses the packaged tutorial extract examples/case_001 (downsampled).

Overview (about 2 minutes)
  • User provides: a 3D knee MRI in .nii.gz (NIfTI).
  • Software produces: a segmentation NIfTI (integer labels per voxel), optional overlay PNG, optional provenance JSON.
  • Research use: draft structure masks for further analysis — not a clinical device.
  • This demo executes: the cached path (load packaged prediction → validate → save/visualise). It does not run full nnU-Net GPU inference unless you configure optional weights separately.
Processing flow: real inference vs tutorial cache 
Real inference (optional):
  MRI → preprocess / nnU-Net predict → segmentation NIfTI → save

Cached tutorial (default here):
  Example MRI + precomputed prediction → validate/load → save result + overlay

Mode label: “live lab” = Python ran on this machine. It still uses the cached prediction unless you enable optional inference.
